# dio-front-repo-base

Repositório criado como parte do desafio prático de Git e GitHub da Digital Innovation One (DIO).

## Objetivo
Praticar conceitos fundamentais de versionamento utilizando Git e GitHub, incluindo:
- Criação de repositórios
- Versionamento de arquivos
- Commits e histórico
- Sincronização com repositórios remotos

## Conteúdo
- Anotações das aulas
- Exercícios práticos
- Testes de comandos Git

Este repositório faz parte do meu processo de aprendizado em desenvolvimento e será atualizado conforme avanço nos estudos.
